VMMC Macau International Airport Upgrade Pack

Overview

A tailored scenery enhancement pack for Macau International Airport (VMMC) in Aerofly FS. This mod fixes parking stand layouts and optimizes ground lighting effects.

Specifications & Compatibility

  • Platform: Aerofly FS 4 (PC / Android / iOS)
  • Contents: Ground lighting corrections, apron markings
  • File Size: 23.90 KB
  • Version: v1.0.0

Installation Guide

  1. PC Users (Windows):
    • Download and extract the archive. You will find airport and poi folders.
    • Navigate to: C:\Users\username\Documents\Aerofly FS 4\scenery\airports\
    • Manually create a new folder named cn inside this directory (if it does not already exist).
    • Move the folder(s) inside the airport folder into this cn directory (i.e., ...\scenery\airports\cn\).
    • Copy the folder(s) inside the poi folder into:
      C:\Users\username\Documents\Aerofly FS 4\scenery\poi\
      (Note: Replace username in the path with your own Windows user account name)
  2. Mobile Devices (Android):
    • No extraction required. Directly copy (⚠️ Important: Please ensure you COPY the file, do not move/cut it) the downloaded .tme file into the following application data directory:
      storage/emulated/0/Android/data/com.aerofly.aeroflyfsg1/files/
  3. Verification:
    • Launch Aerofly FS, locate VMMC on the navigation map or airport selection menu, and spawn in.
